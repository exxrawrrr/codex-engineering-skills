# Security Policy

These skills contain engineering guidance, not a security guarantee.

For non-sensitive documentation or guidance problems, open an issue.

Do not post secrets, credentials, private user data, or exploit material containing live sensitive values in public issues. Use a minimal reproduction with sensitive data removed.

The suite favors deterministic controls, least privilege, public-network-only crawling by default, explicit local-network opt-in, untrusted-content isolation, no secrets in logs, and human approval for high-impact actions.
